## Verdict
**The archived agent dataset is physically invalid and must not be quoted.**
Root cause (verified in `runs/jobs/session-atomagent-demo1/logs/`): the "production"
run executed with **no time-integrating fix** (`WARNING: No fixes with time
integration` — Temp frozen at 1.5702 for 100k steps), and `output/stress.dat`
was actually harvested from the earlier `build.log` run whose energy diverged
by 8 orders of magnitude. The Simulator nonetheless reported "Run succeeded".

**Action for the paper:** re-run demo1 on the fixed harness (validation gates
now attach a FAIL verdict to such runs automatically) and regenerate this
overlay with `python analysis/reference_comparison/compare_demo1.py`.
