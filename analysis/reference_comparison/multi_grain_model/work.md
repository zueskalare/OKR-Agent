## Verdict
The agent's `demo2_success_1` run is a **pipeline** success but a limited
**science** result: its curve covers only the first ~0.5% strain of a pilot
model, and **neither** system was relaxed to zero pressure before loading
(both curves start at multi-GPa compressive stress — magnitudes carry that
offset). Curve *shapes* over the common strain window are comparable; absolute
strengths are not directly quotable.

**Action for the paper:** re-run demo2 on the fixed harness with a
zero-pressure relaxation stage (the ε=0 residual-stress gate now flags this
automatically), full 150 Å model, and the full strain ramp; then regenerate
the overlay with `python analysis/reference_comparison/compare_demo2.py`.
